# Portfólio de certificações | Lucas Martins Lima

Este repositório contém um portfólio estático de certificações e cursos concluídos, pronto para publicação no GitHub Pages.

## Arquivos
- `index.html`: site completo em um único HTML, com CSS, JavaScript e QR Codes incorporados.
- `certificados/`: local reservado para os PDFs originais dos cursos.
- `GUIA-PUBLICACAO-GITHUB.md`: passo a passo de publicação.
- `.nojekyll`: evita processamento desnecessário do Jekyll.

## Adicionar PDFs
Use os nomes exatos listados em `certificados/LEIA-ME.txt`. Os cartões identificam os arquivos disponíveis automaticamente quando o site está hospedado.

## Atualizar cursos
As próximas mudanças devem ser feitas no mesmo `index.html`, no array `credentials`. Não é necessário criar outra página ou outro HTML.

## Privacidade
O GitHub Pages é público. Não publique documentos com CPF ou dados pessoais desnecessários. O certificado IFRS informado para este projeto contém CPF. Não publique o original sem revisar o dado; uma edição para ocultá-lo pode afetar uma assinatura digital incorporada. Se tiver dúvida, mantenha o PDF privado e use a validação por código.
